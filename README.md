# 🪄 带团妙妙小工具（COC 7th）

克苏鲁跑团（Call of Cthulhu 7th）用的本地 GM 工具：**一个网页文件，双击就能用**。
能读人物卡 `.xlsx` 直接建调查员库，管 NPC / 敌人、地图与路线时间、战斗桌、剧本笔记、骰子与 SAN 检定，
右半屏还能**看模组**和**查规则书**，最后把角色**整张导回人物卡 `.xlsx`**（公式、合并、样式都在，接着用 Excel 手写）。
右半屏还有**🧰 更多小玩意儿**：随机名字 / NPC / 地点，「选日期 + 选地点」看当天月相与日月出没，
还有 **✍️ KP正在瞎编！** —— 一句话或几个标签就出一段能直接念的场景 / 怪物描写（纯本地素材，不联网、不接 AI）。

**本工具只适配 4 张人物卡**（第一次打开会弹窗说明，并给空白卡下载）：

| 卡 | 说明 |
|---|---|
| COC7空白卡23（粉）-坪改 | 常用主卡，职业列表带原版与《日本秘史》扩展 |
| COC7空白卡CY23Final | 与粉卡同源，打印版面更清爽 |
| COC7空白卡CY2lusFinal | 多一张「建卡」表：先在建卡表掷骰，人物卡自动带出属性 |
| 中式职业扩展COC7空白卡1.6 | 职业列表换成中式职业（更夫 / 镖师 / 教书先生 …），本职技能按它自己的表算 |

4 张卡的读写都按**各卡自己的工作表**走（值框 / 技能表 / 武器表 / 本职技能 / 职业列表 / 附表雷达），
所以「职业不同、本职技能不同、武器表不同」的卡都会各自算对。

同一份源码出两种成品：

| 成品 | 是什么 | 什么时候用 |
|---|---|---|
| `offline.html` | **离线单文件版**：xlsx 引擎、4 张卡模板、规则书都内嵌，双击即用、不联网 | 本地跑团 / 日常使用（`Documents/跑团/小工具/index.html` 用的就是它） |
| `index.html` | **在线多文件版**：页面很小，按序加载 `src/*.js`；xlsx 引擎、卡模板、规则书、天文计算库、PDF 阅读器都按需取 | 放 GitHub Pages，手机或别的电脑打开（需要联网） |

所有数据（调查员、NPC、地图、笔记、骰子日志、背景设置）都只存在**本机浏览器**里，不上传任何服务器；
请常用右上角 **⬇ 备份数据** 导出 JSON 存档。右上角「⚠️ 清空全部本地数据」会把调查员 / NPC / 地图 / 战斗记录
和**上传的模组**一起清掉（模组存在浏览器 IndexedDB 里，也一并清）。

## 一、功能

### 📋 调查员
- **拖卡即入库**：把受支持的 4 张卡里任意一张填好的 `.xlsx` 拖进虚线框（或点击选择）就直接进调查员库，不弹窗；
  导入预览会写「识别为哪张卡」，导出时也填回**同一张**模板。
  读到姓名 / 玩家 / 职业 / 时代 / 性别 / 年龄 / 住地 / 故乡、9 项属性、全部技能、**武器表**、**随身物品**
  （原卡右侧「背包格」那一列也算随身物品）、法术、现金 / 信用评级 / 其他资产表、背景 9 条（拆成独立条目）+ 背景故事正文、调查员经历。
  武器行「只选了类型、名字留空」也照样读得出来（用类型当显示名）；卡右上角的**任意特长**那几格也会一起读进来。
- **标签栏 / 导入栏可收起**：调查员页最左的标签栏和上面的导入框，点标题就能展开 / 收起，状态记在本机，界面更清爽。
- **小卡**：左上信息 + 右上头像（**点小卡头像就能直接换图**）、HP / SAN / MP 彩条、法术标签、DB 与武器、剧情道具；
  经历越多外框越花（铁 → 铜 → 银 → 金 → 白金 → 翡翠发光 → 棱镜流光 → 火焰 → 火焰 + 星星）。
- **便签标签**：页面最左侧标签栏可自定义标签（emoji、任意长度、可改色、可删）；点选标签再点小卡，或直接把标签拖到小卡上；
  每张小卡最多 6 个，可跨卡拖动或移除。
- **✏️ 编辑弹窗**：属性（旁边就是**人物数值雷达图**，对齐卡里「附表」那张九维图，改属性实时重画）、护甲（含参考防具预置）、HP / SAN / MP、技能（自动分「已加点 / 更多默认值」两区）、
  武器、**背包 / 随身用品**、剧情道具、法术、资产（现金 / 货币 / 其他资产表）、背景 9 条 + 正文、调查员经历，全在这里改。
  信用评级与卡右上角「任意特长」不占详情卡版面：导入时照读、导出时照写回（想改信用评级就改技能里的「信用评级」）。
- **⬇ 导出卡**：把这张卡填回**你导入的那张卡**的模板，导出 `团名-角色名.xlsx`（规则见第三节）。

### 👤 NPC 与敌人
- 先选**类别**（人类 / 动物 / 神话生物，默认「全部」）再选**具体条目** → 设数量 → 生成；
  属性按规则书的骰式**现掷**（人类 3D6×5 / 2D6+6×5，怪物如 CON 2D6×5），所以每次生成都是新的随机值、往往是 5 的倍数。
  神话生物已按规则书预填标志性法术，数值 / 阵营 / 法术生成后都能再改。
- 四列小卡：盟友 / 中立 / 敌人 / 其他，列名可点标题改，卡片可拖拽排序（手机上用 ◀ ▶）。
- 小卡**不显示备注 / 描述**（一行描述会把卡片撑成好几行，挤掉头像与彩条）；备注存在后台，
  点小卡进详情卡的「背景备注」里写 / 看，生成时模板给的提示也会预填在那里。

### 🗺️ 地图·路线
- **上面一条二级菜单栏**：🗺 地图（切地图 / 载入预设 / 缩放 / 比例尺 / 换底图）· 🧍 地图角色 · 🧩 摆件素材 ·
  🚗 载具·时间速度 —— 点哪个开哪个（一次只开一个），再点一下收起；下面**整幅地图占满宽度**，
  再往下依次是路线时间计算 / 地点 / 道路路径。
- **最多 3 张地图**（页签切换、可改名 / 删除），内置 42 张预设（城市、海岸、室内、地下…），也能上传自己的底图。
  一张地图都没有时，下面的地点 / 道路编辑区不会消失，会提示你「＋ 新建地图」；「载具·时间速度」里那张默认速度表也一直在。
- **三种工具**（工具栏与全屏图标条里都有）：
  - **🖱 拖动地点**：只挪地点；拖动时相连道路的 km **实时重算**并写在图上（室内 / 地下地图不显示里程）。
  - **🧍 移动角色/摆件**：只挪地图上的角色与摆件素材，**不动地点和道路**。
  - **📍 添加地点**：点一下图上位置落点。
- **比例尺**「1格 = __ km」→ 设：改了之后，自动算出来的里程按新比例尺重算，手改过的里程保持不动；
  **切换预设地图时里程已经按当前比例尺算好**，不用再点一次「设」。
- **打开 / 切换 / 缩放地图都会自动居中**（电脑、手机、平板都一样），不再一进来就贴在左上角；
  缩放时看着的那一块保持在视线中间。
- 摆件素材近 60 种，可上传自定义图片；在「🧍 地图角色」里点角色上地图，再拖到位置。
- **载具·时间速度**（菜单栏最右那个）：速度表一行四个（窄屏自动减列），可改速度 / 分配 / 备注；
  选起终点 + 载具 → 按道路算最短时间路线，逐段可换乘，附到达时刻。

### ⚔️ 战斗
- **上面一条二级菜单栏**：👥 添加角色（调查员 / NPC / 临时成员）· ⚔️ 战斗桌（本次战斗标题 / 下一轮 / 清空）——
  点开就用、再点收起（一次只开一个）；下面**战斗场景占满宽度**，再往下依次是战斗成员表、行动日志。
  点角色后，**详情浮在屏幕最左侧**（不再挤在场景下面），切到别的页或点「收起」就收起来。
  场景里**拖动角色只挪位置、不会弹详情**；想看详情**双击角色**（全屏时点空白处收起详情）。
- 加入成员后自动左右排布（调查员 / 盟友在左，其余靠右，可拖动）；场景头像下方 HP / SAN / MP 三条彩条。
- 面板里改 HP / SAN / MP / 护甲、实时增删武器 / 道具 / 法术，都会**自动同步**回角色档案与小卡（也可点「↻ 同步档案」手动同步）。
- 状态徽标：💫 眩晕 · 🩸 濒死 · 💤 昏迷 · 💀 死亡 · ⚠️ 异常 · ✅ 复原；
  攻击按技能判定伤害，自动扣 HP 与弹匣 / 道具；不用先选目标，直接打**对面第一个还站着的**成员。
- 🎨 场景道具素材库（油桶、爆炸、桌子、雕像…共 64 种，另可上传自己的图片），放进场景后可拖可删。

### 📜 剧本/笔记 与 🎲 骰子
两个和页面平级的**悬浮栏目**（不切换页面，一次只开一个）：
- **📜 剧本/笔记**：3 张备用笔记卡，可改名、各自自动保存；点调查员 / NPC 快捷链接会往笔记里插一个可点标签，点标签直接开角色详情。
- **🎲 掷骰**：个数 / 面数随便填（默认 1D100）。可指定角色与技能 —— 技能表按数值从高到低排，已加点带 ☆；
  1D100 会自动给出普通 / 困难 / 极难 / 大成功 / 大失败，大成功与大失败阈值可自定。掷骰日志关闭面板也不清空。
- **🧠 SAN 检定**（骰子台第二个页签）：理智骰（成功 = 掷出 ≤ 当前 SAN）→ 失败掷损失骰 → 损失够大自动做 INT 判定 →
  按规则书 1D10 疯狂发作表（或你自定义的症状列表）给出症状与持续轮数；SAN 损失会**写回该角色档案、战斗成员与小卡**。

### 📖 模组 与 📚 规则书（右半屏）
菜单栏点 **📖 模组** 或 **📚 规则书**，页面就按**左右分栏**：左半边还是你正在用的功能，右半边是模组 / 规则书面板；
再点一次同一个按钮收起。中间的细条可拖动调宽度，双击回到一半一半，比例记在本机。
**窄屏（手机 / 平板竖屏，≤900px）自动改成整屏浮层**：点「📖 模组」直接铺满整屏，右上角 ✕ 收起，
不用再往下滚着找（以前是接在左半边下面，手机上看着像没反应）。
- **📖 模组**：**多文件**面板。「⬆ 添加文件」可多选、「📁 文件夹」选整个目录，或直接把**文件 / 文件夹拖到窗口里任何地方**
  （会自动打开模组栏；拖拽时有「松手放进模组」提示。`dragover` / `drop` 都会 `preventDefault`，
  所以不会像以前那样被浏览器接管 —— PDF / 图片跳新标签页、docx 静默下载；人物卡 `.xlsx` 仍旧归左边导入框，模组栏不抢）
  （有文件就直接用浏览器给的 `dt.files`，只有拖**文件夹**时 `dt.files` 才为空、这时才走 `webkitGetAsEntry` 递归读目录；
  跳过隐藏文件与 `~$` 临时文件，按文件名自然排序）。支持 **PDF**、**Word（.docx）**、
  **图片**（png / jpg / gif / webp / bmp / svg）、**txt / md**；不支持的老格式（.doc / .rtf / .pptx…）会给出「另存为 PDF」的提示。
  手机上点「⬆ 添加文件」从「文件」App 里挑（可以一次选多个；Safari 不支持选目录，所以手机不显示「📁 文件夹」，
  这是故意藏起来的，不是坏了。文件框也改成了移出屏幕渲染而不是 `display:none`，并且**先把 FileList 抄成数组再清空 input** ——
  iOS Safari 上直接清 `input.value` 会把 `files` 一起清掉，那正是「手机上选完文件没反应」的老毛病）。
  加进来的文件在顶部排成一排**标签页**（横向可滚动，带类型图标与 ✕ 单删），点标签切换、`🗑 全部清除` 一次清空；
  **标签可以按住拖动换顺序**（顺序会记住），一行放不下时**标签名自动压缩**（全称 → 省略号 → 只剩两个字），
  所以标签多/名字长也不会把那条挤变形（这条高度是固定的）。
  Word 自带解压 + 排版（不靠浏览器能力，老浏览器也能开），标题 / **表格** / **正文图片** / 分页线都保留，还能 A＋ / A－ 调字号；
  PDF 用**工具自带的阅读器**（src/33-pdf-viewer.js，内核是 Mozilla 的 pdf.js）：**整本一页接一页连续排开**，
  手机 / 平板上**上下滑动就是翻页**（电脑上滚轮 / 拖动一样顺），工具条上的页码跟着「当前看到的那一页」走，
  每份文件各自记住看到第几页。工具条还有上一页 / 下一页 / 输页码 / A＋A－ / **适宽**，手机与平板能**双指捏合**缩放，
  「☰ 跳页」是**快速翻页面板**：PDF 自带书签就先列**书签目录**，没有书签就给**整本页码方格**（点一下直接跳过去），
  也能直接输页码；点「↗ 新窗口」交给系统阅读器。
  （浏览器自带的 iframe 阅读器在 iOS / 安卓上不认 `#page=`、也没有缩放按钮，所以正文改成自己画。
  一列画布只画视口附近那几页，318 页的规则书滚动起来也不卡。）
  图片点一下在「适应窗口 / 原始大小」之间切。
  整份列表存在浏览器 IndexedDB 的一条记录里（PDF / 图片存 blob，Word / 文本存排好的正文），刷新后还在，不上传任何服务器；
  老版本只存过一份模组的记录（key=`module`）会自动迁移成第一个标签页。
- Word / txt 模组上方还有一条**搜索框**：回车高亮所有命中，↑ / ↓（或 n / N）在命中之间跳，并显示「第几条 / 共几条」。
- **📚 规则书**：整套《COC7th 核心规则书》按**原版 PDF**显示在右半屏，表格 / 颜色 / 流程图跟纸书一模一样。
  左侧**书签目录**点一下就跳页，上方输入关键词回车做**全文搜索**，命中页列出来点一条就跳过去。
  正文就是原版 PDF，**上下滑动一路看下去**，翻页 / 缩放 / 跳页走的是同一套自带阅读器
  （点左侧目录、点搜索命中、「☰ 跳页」面板都会**真的翻到那一页**）；左侧目录可以「☰ 收起目录 / 展开目录」（状态记在本机）。
  PDF 在 `assets/rulebook/coc7.pdf`（离线版内联成 base64，在线版按需取），目录 / 检索用的文本在
  `assets/rulebook/coc7.js`，不是 JSON，所以 `file://` 双击打开也能用；
  PDF 阅读器本体（`assets/pdfjs/`）离线版内联、在线版第一次打开 PDF 时才下载。

### 🧰 更多小玩意儿（右半屏第三个面板）
菜单栏点 **🧰 更多小玩意儿**，和模组 / 规则书一样左右分栏（左半边照常带团）。顶上一条子页签切换三个小工具：
- **🎲 跑团随机**：不开新页面、不写大段文字，点一下就有能直接念的素材。
  - **随机名字**：中文 / 英文（带中文翻译）/ 日文（带假名读音）；可选性别，一次 1 / 6 / 12 / 20 个；
    点单个名字即复制，也能整批复制。
  - **随机 NPC**：姓名 / 年龄 / 性别 / 职业 / 性格 / 外貌 / 着装 / 小习惯 / 家庭状况 / 爱好 / 恐惧 / 秘密 / 信仰 / 口头禅（含粗口），
    一次全掷出；**不满意的某一项点那一行的 ⟳ 单独重掷**，其余字段不动；结构化逐行列好，可直接复制。
  - **随机地点**：场所 / 城镇 / 街道 / 建筑 / 房间 五类，每处带一句「拿来就能用」的钩子（例：“地板上有洗不掉的深色污渍”）。
- **🌙 天文·天象**：选**日期** + **地点**（内置 100 来个城市，也能手填经纬度 / 时区），看「当天的天空」——
  月相（名称 / 月龄 / 照明率）、月出月落、日出日落、白昼黑夜时长、**天黑（民用黄昏）与完全黑暗的时段**、
  今晚能看到的**亮星与星座**、**肉眼可见的行星**（带方位与星等）、**流星雨**（峰值前后，含月光影响）、
  **日食 / 月食**（当地可见的日食会算），另有折叠的**本月天象日历**（月相节点 / 流星雨峰值 / 日月食 / 节气）。
  极昼 / 极夜 / 白夜都会照实说明；时间按该城市的**标准时**算（不换算夏令时），查 1920 年代的团很方便。
  天体位置不是自己编的：用 **astronomy-engine**（MIT，原作者 Don Cross，`assets/sky/astronomy.js`），
  离线版内联进单文件，在线版第一次打开「天文·天象」时才按需下载，`index.html` 依旧很小。
- **✍️ KP正在瞎编！**：KP 临场用的**描写助手**。纯本地素材 + 标签解析 + 规则组合，**不联网、不接 AI、不引框架**。
  - **一句话就够**：写「凌晨三点，外面下着瓢泼大雨，废弃病院里特别阴冷」，自动认出
    场景 / 时间 / 天气 / 氛围，点「✍️ 生成」就出一段能直接念的描写。
  - **快捷标签**：场景（12 个，点一下直接出结果）/ 时间 / 天气 / 氛围，可以叠加、可以单个删掉、可以清空。
  - **更多设置**（默认收起）：物体 / 事件 / 描写重点 / 光线 / 情绪 / 异常 / 超自然 / 禁止内容 / 自定义要求。
  - **三种入口共用一套内部条件**（文本 → 快捷标签 → 更多设置 → 自定义要求，越明确越优先），
    互斥条件（深夜 ↔ 白天、晴天 ↔ 暴雨…）会覆盖并提示；但「白天 + 黑暗」「平静 + 紧张」「暴雨 + 压抑」
    「寂静 + 雨声」这类**语义上不冲突**的组合照常共存。
  - **自然语言否定**：说「不要出现怪物」= 禁止（结果里绝不会有怪物，改用异常 / 温度 / 灯光 / 痕迹）；
    说「不要马上出现怪物」= 延迟（它存在，但这一段不露面）。「不要写血腥 / 不要写声音 / 尽量不要出现超自然现象 /
    不希望它立刻攻击」都会变成对应的限制条件。
  - **怪物描写**（独立页签）：深潜者 / 食尸鬼 / 米·戈 / 修格斯 / 夜魇 / 蛇人 / 廷达罗斯猎犬 / 幽魂 / 不可名状之物，
    每只都有**自己的**外貌 / 动作 / 声音 / 气味 / 温度 / 触感 / 环境变化 / 接近时 / 攻击前兆 / 战斗 / 受伤 / 死亡 /
    消失 / 调查员观察素材，不套同一套模板；中英别名都能认。
  - **我的素材**：自己写一句加进来，自动认标签（可以删掉认错的），存在本机、离线可用、参与之后的生成。
  - **结果操作**：再来一段 / 继续（保留当前场景、时间、天气与已建立的事实，不会上一段医院下一段森林）/
    扩写（只加细节，不动已经写出来的句子）/ 选中某句 **🔒 锁定**（重新生成时那句一字不改）/ 复制；
    长度短 / 中 / 长可随时调，变长是把当前内容扩写而不是换一个场景。
  - **素材不够时按层降级**并就地给一句轻提示（不弹窗）：保留你明确给的条件，只放宽次要条件、再用通用素材组合。
  - **不怕连点「再来一段」**：每次重新生成都会同时重挑 **开头类型 / 段落结构 / 描写维度 / 核心素材**，
    并避开最近用过的开头、句式、意象和整句 —— 同一个条件连点 20 次，开头基本不重样（自带压力测试，见下）。
  - **素材按「每段必出」和「随机铺」分开备料**：天气+时间 / 发现尸体 / 氛围 / 物体这类「用户说了就每段都有」的
    句子单独备了 739 条（其中天气+时间合成句 132 条），不会连点几次就老是同一句开头。
  - **15 类叙述入口**（开头结构库）：声音 / 视觉 / 气味 / 触觉 / 动作 / NPC 反应 / 对话 / 环境事实 / 异常细节 /
    天气时间 / 正常转异常 / 异常补环境 / 直接进入事件 / 调查员观察 / 简短事实；另有 **20 套段落骨架**决定一段话
    由哪几种入口按什么顺序铺开，所以不会每段都是「他们看见了……走廊尽头……空气里……」。
  - **写的是 KP 能直接念的话**：口述句库里是短事实、人物动作、对话、调查员观察、突然发现这类句子，
    不是一路堆形容词的文案；每段还会专门留一个位置给「口述句」，不整段都在写景。
  - **你明确给的条件一定在**：说了场景 / 时间 / 天气 / 事件 / 氛围 / 物体，每一段里都有对应的一句
    （天气和时间会给一句同时带上），只有具体那句话会在若干种说法之间轮换，条件不会丢。
  - 素材与同义词词典在 `src/34-kp-desc-data.js` + `src/36-kp-desc-2.js`（纯数据，加素材不用改逻辑），
    生成逻辑在 `src/35-kp-desc.js`。全部是短句 + 标签，离线版照样能用。

### ⛶ 场景全屏、🎨 外观、📱 手机
- 地图与战斗场景都有 **⛶ 全屏**（`Esc` 退出）。全屏后右下角只留一排图标：📋 调查员 / 👤 NPC 与敌人 / 🗺️ 地图路线 /
  ⚔️ 战斗 / 📜 剧本·笔记 / 🎲 骰子 / ↩ 返回；其中 📋 / 👤 / 📜 / 🎲 是压在场景上的半屏浮层，且**一次只开一个**，
  每个浮层都能拖右边框调宽度。战斗中点角色，详情都悬浮在**屏幕最左侧**（普通模式与全屏一样）。
- **🎨 背景**：第一次打开会从**暗金 / 橄榄绿**里随机挑一套当默认皮肤（不再是原来那身深蓝），挑到哪个会写进本机存档，
  **刷新不会变**；也能在「🎨 背景」里换成任意颜色或上传背景图，全站配色（顶栏 / 卡片 / 输入框 / 弹窗 / 二级菜单栏 / 画布底色）都跟着推导，保证文字可读。
  用户自己选的颜色 / 图片**刷新后一定还在**。这里原来有两个坑，都修了：
  ① **启动顺序** —— `applyUiBg` 的启动钩子挂在 `document` 的 `DOMContentLoaded` 上，而 `initApp` 挂在 `window` 上；
  `DOMContentLoaded` 先派发到 `document`、冒泡到 `window`，所以取背景色时 `state` 还没加载完，`if(!state) return` 直接返回 ——
  表现就是「设了自定义背景，一刷新被打回默认色」。现在钩子改挂 `window`，并且 `initApp` 里也兜一遍。
  ② **存哪儿** —— 颜色存 localStorage，**背景图改存 IndexedDB**（localStorage 只有 5MB，图塞进去很容易写失败），
  上传时先缩到 1800px、JPEG 0.82 再存；老存档里已经塞在 state 里的图片会自动搬到 IndexedDB。想还原点「↺ 恢复默认背景」（会重新随机一个默认皮肤）。
- **🐙 装饰**：一层一直漂浮的小图标（章鱼 / 手枪 / 笔记本…），每次开关都换一批，不挡操作。**默认就是开着的**（只有自己点「装饰：关」才关）。
- **📱 手机 / 平板**：按 iPhone 16 / iPhone 17 / iPad mini 6 / iPad Air 4 调过。
  顶栏两行：第一行是「🪄 带团妙妙小工具 + 🎪 本次团名」，第二行是备份 / 背景 / 装饰 / 说明几个小按钮；菜单栏一行横向滚动。
  **「🎪 本次团名」挪到了品牌名那一行**（以前塞在菜单栏中间，iPad mini 横屏会把菜单栏挤成两行、团名输入框还会被切掉）。
  右半屏在窄屏铺满整屏；触屏上不再显示「拖进来」那条虚线提示；弹窗整屏可滚，输入框 ≥16px 不会触发自动放大；
  地图自动适宽、触摸拖拽角色与摆件。
  iPhone 上把 `index.html` 放进「文件」App 用 Safari 打开即可（iOS 对 `file://` 的本地存储有限制，页面会提示，请勤备份）。

## 二、快速开始

**自己用（离线）**：双击 `offline.html`（或 `Documents/跑团/小工具/index.html`）。读卡、导出卡都不需要联网。

**在线版（GitHub Pages）**：把仓库推上去 → 仓库 **Settings → Pages** → Source 选 `main` 分支、目录选 `/ (root)` → 保存，
一分钟后打开 `https://<用户名>.github.io/coc-tool/`。在线版第一次导入 `.xlsx` 会从 CDN（jsdelivr → cdnjs → unpkg 自动重试）加载 xlsx 引擎，需要联网；本地无网请用 `offline.html`。

**基本流程**：调查员页拖卡入库 → ✏️ 改细节 → 顶部「🎪 本次团名」写上这次跑什么 → 跑团中在地图 / 战斗 / 骰子页操作 →
结束后点小卡 **⬇ 导出卡** 拿回 `.xlsx`。

## 三、导出人物卡（写回 Excel 的规则）

点小卡右下角 **⬇ 导出卡**，做两件事：

1. **把这次团的变化写进「调查员经历」**：和**最初导入那张卡**（手动新建的角色则是最初保存时的状态）逐项比对，
   属性 / HP / SAN / MP / 护甲 / MOV / 技能 / 武器 / 背包 / 法术 / 资产的变化写成一行，模组名用「🎪 本次团名」；
   同一个团反复导出只覆盖那一行，不会越写越多。技能变化还会写进卡里的「成长」列（+3 / -3）。
2. **填回「你导入的那张卡的模板」**（`assets/cards/*.xlsx`，粉卡 / CY23 / CY2lus / 中式职业扩展）并下载 **`团名-角色名.xlsx`**：
   逐格改写 XML，所以格子颜色、边框、**合并单元格**和公式都跟原卡一模一样；小卡的「导出的卡」一栏可以改要用哪张模板。

写回时特意保住“卡里能自己算”的能力：
- **武器表**：类型能在卡内「武器列表」里查到 → 保留（没有就补上）模板同款
  `IF($G53=0,"",VLOOKUP($G53,'武器列表 战斗'!$B$2:$I$105,n,FALSE))`（这几张卡的表叫「武器列表 战斗」，旧卡叫「武器列表」，两种都自动认），管住伤害 / 射程 / 贯穿 / 次数 / 装弹量 / 故障值 ——
  **在 Excel 里改类型，这些会自己重算**；自制武器（卡里没有的类型）则把数值写死，绝不留下会算成 `#N/A` / `####` 的公式。
- **成功率**：用 `IFERROR(INDEX/MATCH)` 按「使用技能」在本卡技能表里取总分（困难 = 一半、极难 = 五分之一），
  写「斗殴」也能对上卡里的「格斗：斗殴」；**改技能数值成功率会跟着变**。技能表里查不到时保留卡上原有公式、
  填上原卡数值（换了技能 / 类型 Excel 里照样会重算），不留空也不会出现乱码。
- **技能名分格**：卡里技能名是「类别」+「具体名」两格（如「驾驶：」「摩托」），导出按原卡分段写回，自定义子技能不会再挤成一格。
- **信用评级**：卡上这格本来是公式（按「信用评级」技能算成功率 / 困难 / 极难）。导出保留公式、只更新显示值，
  在 Excel 里改技能熟练度这格会跟着变。
- **任意特长**：卡右上角那几格（BA/BJ × 18~20）导入时读入、导出时按行写回（详情卡里不单独列，不用管它）。
- **新加的武器**：预设武器的写法跟卡里不一样时（分组名「近战小刀」、半角括号「中型剑(佩剑、重剑)」），
  会先查别名表、再拿**武器名字**去「武器列表」里对号，自动归一成卡里的正式类型，导出后照样能自动算。
- **本职★ 列**：只有在职业序号确实存在于**这张卡自己的**「本职技能」表头、且技能名也在表里时才保留查表公式，避免整列 `#N/A`（中式职业扩展那张卡就按它的职业表算）。
- **武器格数**：按卡上实际留的武器行数来写（这几张卡是 6 行），多出来的武器不会写到下面的「资产」表头上，导出时会提示。
- **属性雷达图**：卡里「附表」的九维雷达（力量 / 体质 / 体型 / 敏捷 / 外貌 / 智力 / 意志 / 教育 / 幸运）在详情弹窗里也会画出来。
- 导出时会给工作簿打上“打开重算一次”的标记，所以打开就是正确数字。

## 四、怎么维护

### 环境与常用命令

```bash
npm install          # 第一次（拉 xlsx 与测试用 jsdom）

npm test             # jsdom 回归（对 offline.html 跑，必须全绿）
npm run test:web     # 在线多文件版端到端（启动 + 懒加载 xlsx 读卡）
```

`npm run build:slim`（离线瘦身，仅 `.xlsx`，≈6.2 MB）、`npm run build:web`（在线，`index.html` ≈4.5 KB）。

### 模块化约定（重要）
- 离线版把 `src` 下所有模块拼进**同一个 `<script>`、同一个全局作用域**；在线版按序加载多个 `<script>`。
  两种形态都靠页面里的 `onclick="…"` 字符串调全局函数，所以**不要改成 ES Module、不要引入打包器 / 压缩改名**。
- 模块**编号就是加载顺序**（`01 → 29`），别重排。模块顶层立即执行的代码不能引用更晚模块的函数
  （例：`06` 里用 `function(){ initApp(); }` 包一层再挂 `DOMContentLoaded`）。
- 加功能就新建 `src/NN-xxx.js` 按编号命名，`build.js` 会自动拼入；`npm run check` 会拦住重复的顶层函数名，
  也会检查 `offline.html` 是否与 `src` 同步。
- **顶层变量一定要写 `var` / `const`**：离线版全部模块挤在同一个 `<script>` 里，整段处于严格模式，
  漏一个 `var`（例如写成 `NPC_TPL = [...]`）就会抛 `ReferenceError` 让**整段脚本当场停住**，
  后面模块的顶层代码统统不执行 —— 症状是「`index.html` 好好的，`offline.html` 一堆功能全炸」。
  `npm run check` / `npm test` 里的静态扫描（`test/scan-undef.js`）专门拦这个；
  jsdom 比浏览器宽容（会自动建全局），所以只看 `npm test` 是发现不了的。

### 改东西时的几条经验
- **改 UI 文案 / 按钮**：文案在 `src/08-panel-shell.js`（骨架与内置说明）、`src/17-actor-modal-v3.js`（详情弹窗）、
  `src/11-actor-form.js`（弹窗里的行模板）。改函数名记得同步搜页面字符串里的 `onclick`。
- **改读卡**：`src/parse-card.js`（含合并单元格与 W..Z 标签列），兼容原版与苹狗 / 神仙索两种排布；
  改完一定跑 `npm test`，里面有真实卡的断言。
- **改导出**：`src/25-card-export.js` 分两部分 —— `cardWritesFor()` 决定“哪个格子写什么值”，
  `buildCardXlsx()` 负责真正改写模板 XML（保留样式 `s=` 与合并）。模板格子变动时先看 `tplRows.__f`（模板原有公式）。
- **换 / 加人物卡模板**：把新的 `.xlsx` 放进 `assets/cards/`，在 `src/26-cards.js` 的 `COC_CARDS` 里加一条，
  并在 `build.js` 的 `CARD_FILES` 里补上 id —— 离线版会在构建时内联，在线版按需 fetch。
  读卡 / 写卡会自动按该卡的「武器列表 / 本职技能 / 职业列表」查表，不用另外写代码。
- **改规则书**：换了 PDF 就放成 `assets/rulebook/coc7.pdf`（构建会把它内联 / 上线），再重跑
  `python3 tools/rulebook/build-rulebook.py`（需 `pip install pymupdf`）重新生成给目录 / 检索用的
  `assets/rulebook/coc7.js`，最后 `npm run build:all`。缺 PDF 时构建会直接报错，不会静默漏掉。
- **升级 PDF 阅读器**：`assets/pdfjs/` 下是 pdf.js 的 **legacy UMD** 构建（`pdf.min.js` + `pdf.worker.min.js`，
  取自 `npm i pdfjs-dist@3.11.174` 的 `legacy/build/`）。换版本时保持「UMD 的 .js 两个文件」这一形态就好
  （阅读器默认走主线程：worker 脚本会把 `WorkerMessageHandler` 挂到 `globalThis`，pdf.js 看到它就不建 Worker，
  `file://` 双击打开也能用）。换完 `npm run build:all`，再用手机 / 平板真机点开规则书翻两页确认。
- **换标签图标**：把新图缩成 128×128 或 256×256 存成 `assets/favicon.png`（例：
  `sips -Z 256 新图.png --out assets/favicon.png`），再 `npm run build:all` 即可；
  图标链接写在 `src/skeleton.html` 的 `<head>`（`rel="icon"`，在线版多一条 `apple-touch-icon`），
  构建脚本负责替换 `__ICON__`：离线版内联成 data URI，在线版指向 `assets/favicon.png`。
- **改样式**：`src/style.css`；自定义背景配色由 `src/21-theme-bg.js` 推导，新增颜色尽量用现有变量。
